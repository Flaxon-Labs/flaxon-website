Flaxon playground

Try a route definition

This small browser playground executes Python with a minimal Flaxon route shim and displays the routes it registers. It does not start an HTTP server, install packages, connect to databases, or run untrusted code on the Flaxon website.

Use it to learn decorator and path syntax. Test a real application locally with flaxon run app:app --reload and the test client.
