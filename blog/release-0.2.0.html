Flaxon v0.2.0 — Protocol Hardening

August 2026 Aldane Hutchinson 4 min read

We're excited to announce Flaxon v0.2.0 — the Protocol Hardening release.

This release focuses on making Flaxon more robust, production-ready, and compliant with ASGI standards. While 0.1.0 established the foundation, 0.2.0 strengthens the core with protocol conformance, better error handling, and improved middleware.

What's New

ASGI Protocol Conformance

Flaxon now passes comprehensive ASGI conformance tests, ensuring compatibility with all major ASGI servers including Uvicorn, Daphne, and Hypercorn.

# Now fully ASGI 3.0 compliant
async def __call__(self, scope, receive, send):
    if scope["type"] == "http":
        await self._handle_http(scope, receive, send)
    elif scope["type"] == "websocket":
        await self._handle_websocket(scope, receive, send)
    elif scope["type"] == "lifespan":
        await self._handle_lifespan(receive, send)

Multipart Uploads

File uploads are now fully supported with streaming multipart parsing, validation, and storage adapters.

from flaxon.files import FileUpload, FileStorage

upload = FileUpload(max_size=100 * 1024 * 1024)
storage = FileStorage("uploads")

@app.post("/upload")
async def upload_file(request):
    files = await upload.parse(request)
    for file in files:
        path = storage.save(file)
    return {"uploaded": True}

Improved Middleware

  • RecoveryMiddleware — Catches exceptions and returns safe responses
  • BodyLimitMiddleware — Limits request body sizes
  • TimeoutMiddleware — Sets request timeouts
  • ProxyHeadersMiddleware — Handles X-Forwarded-* headers

Better Error Handling

Error responses are now more consistent with standardized error codes and improved redaction of sensitive data.

{
  "success": false,
  "error": {
    "code": "FX-HTTP-404",
    "message": "User not found",
    "request_id": "fx_abc123def456"
  }
}

Enhanced Testing Utilities

  • WebSocket test client with full message support
  • Assertion helpers for common test patterns
  • Database test mixins
  • Factory and fixture support

Upgrade Guide

pip install --upgrade flaxon
Breaking Changes
  • Field classes renamed: String → StrField, Integer → IntField
  • Static file serving now requires explicit route
  • Session cookie handling improved with secure defaults

What's Next

Flaxon 0.3.0 will focus on sessions, OpenAPI documentation, health checks, and structured logging. We're also working on the plugin system for 0.4.0.
