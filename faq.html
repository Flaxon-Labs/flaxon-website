Frequently Asked Questions

Common questions about Flaxon.

Flaxon is a technology-neutral, async-first Python backend framework that combines Flask-like ease of use with production-grade features. It's designed for APIs, real-time applications, mobile backends, and structured enterprise systems.
  • vs Flask: Flaxon is async-first with built-in WebSocket support and optional large-application structure.
  • vs Django: Flaxon is technology-neutral — no forced ORM, templates, or admin interface.
  • vs FastAPI: Flaxon offers Flask-style routing (decorators) and optional Jinax templates for HTML rendering.
Flaxon is currently in alpha. It is suitable for evaluation, experimentation, and learning. Production use is possible with careful testing and monitoring, but the API is not yet stable. The 1.0 release is planned for late 2026.
Flaxon is database-agnostic. You can use any database with any Python driver or ORM. Built-in adapters include PostgreSQL (asyncpg), SQLite (aiosqlite), MySQL (aiomysql), MongoDB (motor), and Redis (redis-py).
