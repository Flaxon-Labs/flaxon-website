Security Features

Built-in protections that work out of the box

🛡️

Autoescaping

Jinja2 templates automatically escape content to prevent XSS attacks. Raw HTML requires explicit opt-in.

✅

Request Validation

Declarative schemas validate all incoming data with automatic 422 responses for invalid requests.

🔐

Security Headers

X-Content-Type-Options, X-Frame-Options, Referrer-Policy, and Permissions-Policy headers set by default.

🚫

Rate Limiting

Configurable rate limiting to prevent abuse and DoS attacks. Distributed rate limiting support via Redis.

🔍

Data Redaction

Passwords, tokens, and secrets are automatically redacted from debug output and error responses.

🔑

CSRF Protection

Built-in CSRF token validation for state-changing operations. Seamless integration with forms and APIs.

🛡️

Security Policy

Flaxon follows responsible disclosure. We take security seriously and respond to vulnerability reports promptly.
