Features

Built for Modern Backend Development

Everything you need to build production-grade Python applications.

Async-First ASGI

Built for high-concurrency I/O workloads with Python's asyncio. Handle thousands of connections efficiently.

simple-Style Routing

Familiar and intuitive decorator-based route definitions. Start simple, scale to complex applications.

Technology Neutral

Use any frontend, database, ORM, or client. React, Vue, Android, PostgreSQL, SQLite — your choice.

Request Validation

Declarative schemas with automatic 422 responses. Validate request data with Python dataclasses.

WebSocket Support

Real-time communication with room broadcasting. Built-in support for chat, notifications, and live data.

Readable Debugger

Explains failures in plain language with request context. No more cryptic tracebacks.

Optional Structure

Start simple, scale to large applications. Introduce routers, services, middleware, and plugins as you grow.

CLI Tools

Run, inspect, doctor, and generate projects. Powerful command-line tools for development.
