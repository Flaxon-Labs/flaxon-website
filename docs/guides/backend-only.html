Use Flaxon as a backend

Flaxon supports standalone JSON APIs and WebSocket services as well as full-stack applications. Keep your frontend in React, a mobile app, or another service, and use Flaxon for the HTTP boundary.

Install and run a JSON API

pip install "flaxon[standard]"

Create app.py:

from flaxon import Flaxon

app = Flaxon("hello-api", debug=True)

@app.get("/")
async def home():
    return {"message": "Hello from Flaxon"}

@app.get("/users/<int:user_id>")
async def get_user(user_id: int):
    return {"id": user_id}

flaxon run app:app --reload

Open http://127.0.0.1:8000/. These routes return JSON; you do not need to create Teloce components, templates, or an Admin dashboard.

Use explicit allowed origins for browser clients. For production, disable debug and reload, configure secrets and persistent/shared infrastructure, and follow the deployment guide.

Add full-stack features when you need them

You can add Jinax server-rendered pages, Teloce components, and Admin and CMS to an API application. The backend guides remain useful for either approach.
