Pydantic integration

Pydantic is an optional integration. Flaxon keeps its native validation system independent while allowing endpoints to accept Pydantic BaseModel parameters and return model instances.

Install

python -m pip install "flaxon[pydantic]" email-validator

Validate request bodies

from pydantic import BaseModel, EmailStr
from flaxon import Flaxon

app = Flaxon("accounts")

class CreateUser(BaseModel):
    name: str
    email: EmailStr
    age: int

@app.post("/users")
async def create_user(user: CreateUser) -> CreateUser:
    return user

Malformed JSON returns 400. Valid JSON that fails the Pydantic model returns 422 with field-level errors under error.fields.

Response models

@app.get("/users/<user_id>")
async def get_user(user_id: str) -> CreateUser:
    return CreateUser(name="Ava", email="ava@example.com", age=28)

Flaxon serializes returned models with model_dump(). Native Schema classes remain available when you do not want an additional dependency.

Use Pydantic in modules

from flaxon.modules import FlaxonModule
from pydantic import BaseModel, EmailStr

accounts = FlaxonModule("accounts")

class CreateAccount(BaseModel):
    name: str
    email: EmailStr

@accounts.post("/")
async def create_account(account: CreateAccount) -> CreateAccount:
    return account

app.mount_module(accounts, prefix="/api/accounts")

Keep persistence in a service or repository rather than in the Pydantic model or route handler. See the Modules guide for application-factory composition.
