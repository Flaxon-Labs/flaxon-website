OpenAPI, Swagger UI, and ReDoc

Flaxon can generate an OpenAPI 3.1 document from the routes already registered on the application. The same schema powers an interactive Swagger UI and a ReDoc reference page.

Enable interactive documentation

from flaxon import Flaxon

app = Flaxon("catalog", openapi=True)

# Generated endpoints:
# /openapi.json - OpenAPI 3.1 JSON
# /docs         - Swagger UI with Try it out
# /redoc        - ReDoc reference browser

OpenAPI is opt-in. An application that does not pass openapi=True does not mount these routes.

Configure URLs and metadata

app = Flaxon(
    "catalog",
    openapi={
        "title": "Catalog API",
        "version": "2026.1",
        "description": "Inventory and ordering API.",
        "docs_url": "/api/docs",
        "redoc_url": "/api/reference",
        "openapi_url": "/api/openapi.json",
    },
)

Document typed endpoints

from flaxon import Query

@app.get(
    "/products/<int:product_id>",
    summary="Get a product",
    tags=["products"],
    operation_id="get_product",
)
async def get_product(
    product_id: int,
    page: int = Query(1, ge=1),
    search: str = Query("", max_length=120),
):
    return {"id": product_id, "page": page, "search": search}

Path converters and Query declarations become schema parameters and are validated at runtime. Invalid values use Flaxon's normal 422 validation response.

Use schemas and Pydantic

from flaxon.validation import IntField, Schema, StrField

class CreateProduct(Schema):
    name = StrField(required=True, min_length=2, max_length=120)
    stock = IntField(required=True, minimum=0)

@app.post("/products", summary="Create a product", tags=["products"])
async def create_product(product: CreateProduct) -> CreateProduct:
    return product

Native Flaxon schemas work without extra dependencies. Install flaxon[pydantic] when you want Pydantic models; their model_json_schema() output is included in the OpenAPI components.

Modules and routers

Routes included with include_router() or mounted with mount_module() are discovered from the final application registry. Metadata stays with the feature that owns the route.

Protect documentation

from flaxon import HTTPException

async def docs_guard(request):
    if request.headers.get("x-docs-key") != "internal-preview":
        raise HTTPException(403, "Documentation is restricted.")
    return True

app.enable_openapi(
    title="Internal API",
    docs_guard=docs_guard,
    protect_docs=True,
)

OpenAPI describes the contract; it does not authenticate requests. Keep the application's real authentication and authorization in place. For private deployments, serve Swagger and ReDoc assets from your own host.

Export and check the schema

flaxon docs app:app --output openapi.json
flaxon docs app:app --output openapi.json --check

The check compares parsed JSON and returns a non-zero exit code when the checked-in schema is missing, invalid, or out of date.

WebSocket routes are not represented by OpenAPI; document their messages separately in the WebSockets guide.
