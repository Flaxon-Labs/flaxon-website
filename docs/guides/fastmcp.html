FastMCP integration

FastMCP is an optional integration for exposing Flaxon operations as Model Context Protocol tools, resources, and prompts. It can live beside normal HTTP, GraphQL, WebSocket, Admin, and CMS routes.

Install and mount

python -m pip install "flaxon[mcp]"
from fastmcp import FastMCP
from flaxon import Flaxon
from flaxon.integrations.fastmcp import mount_fastmcp

app = Flaxon("store", debug=True)
mcp = FastMCP("Store Tools")

@mcp.tool
async def find_product(name: str) -> dict[str, str | bool]:
    """Find a product in the store catalog."""
    return {"name": name, "available": True}

mount_fastmcp(app, mcp, path="/mcp", require_auth=False)

The mounted endpoint is /mcp. Flaxon owns the ASGI lifecycle; do not call mcp.run() inside an endpoint or startup callback.

Production authentication

mount_fastmcp(
    app,
    mcp,
    path="/mcp",
    auth=auth_provider,
    require_auth=True,
    host_origin_protection=True,
    allowed_hosts=["api.example.com"],
    allowed_origins=["https://console.example.com"],
)

Do not expose remote tools without authentication. Apply authorization, rate limits, input validation, audit logging, and business rules before allowing side effects.

Multiple workers

mount_fastmcp(app, mcp, path="/mcp", stateless_http=True)

FastMCP's default Streamable HTTP sessions are process-local. Use stateless mode for multiple workers and put application state and event storage in shared Redis or database infrastructure.

Keep protocol boundaries clear

  • Use Flaxon routes for normal HTTP APIs.
  • Use GraphQL for typed graph queries.
  • Use WebSockets for application real-time features.
  • Use FastMCP for tools and resources consumed by MCP clients.

FastMCP remains the source of truth for MCP protocol behavior; Flaxon's adapter provides mounting and lifecycle composition.
