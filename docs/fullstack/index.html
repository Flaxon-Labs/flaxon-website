Learn full-stack Flaxon in ten lessons

Build a Taskboard, then explore other ways to use the same Python application: interactive Teloce pages, server-rendered Jinax pages, feature modules, API clients and live interfaces. The lessons use readable Python and TypeScript, explicit file names and checks you can perform yourself.

Flaxon owns HTTP, validation, authentication, persistence integration and WebSockets. Teloce compiles .html/.vel components and runs their reactive interface in the browser. MinifyJS optimizes production JavaScript. These are different jobs: TypeScript cannot replace server validation, and a browser router cannot authorize a database operation.

Start with the quick start. Each lesson explains which files to change. Code marked as a fragment extends the earlier app; it is not a separate complete application. The course example provides a runnable .html interface with TypeScript helpers. The CDN converter provides a .vel variant.

9. Add live updates and test the full boundary WebSockets, subscriptions, signals and integration tests
10. Build, deploy and maintain the complete application Builds, tasks, API contracts, extensions and deployment

TypeScript support depends on the installed Teloce version. Its transpiler removes supported type syntax; it is not a full semantic type checker. Browser HMR, automatic SSR and automatic account/database setup are not implied by full-stack.
