Admin API

The Admin API provides authenticated model management, CMS operations, production services, and a microservice control plane. Browser mutations require the Admin session cookie and X-CSRF-Token.

Dashboard and extension API

from flaxon.admin import AdminDashboard

admin = AdminDashboard(
    app,
    storage_path="admin.sqlite3",
    redis_url="redis://127.0.0.1:6379/0",
)

# Register model adapters and mount custom FlaxonModule pages.
admin.register(products, name="product", fields=["id", "name"])
admin.mount_module(reports, prefix="/admin/extensions/reports")

Production service objects

from flaxon.admin import (
    DurableJobStore, DurableJobWorker, ImmutableAuditLog,
    NotificationService, ResumableUploadStore, WebAuthnService,
)
ServicePurpose
DurableJobStorePersist queued, running, completed, and failed jobs with retry metadata.
DurableJobWorkerRegister named handlers and process due jobs.
ImmutableAuditLogAppend hash-chained records and verify tamper evidence.
NotificationServiceStore notification preferences and per-user delivery records.
ResumableUploadStorePersist upload sessions, chunks, expiry, and final SHA-256 validation.
WebAuthnServiceDelegate credential registration and assertion ceremonies to an injected provider.

Important endpoints

  • /admin/media/resumable creates and completes chunked uploads.
  • /admin/media/{filename} updates metadata, signed URLs, and deletes media.
  • /admin/notifications/preferences manages per-user delivery preferences.
  • /admin/audit/verify verifies the persisted audit hash chain.
  • /admin/profile/webauthn/* handles provider-backed WebAuthn ceremonies.
  • /admin/profile/trusted-devices lists and revokes trusted devices.
  • /admin/cms/api/scheduler/jobs exposes scheduled-publication history and retries.
  • /admin/cms/api/media lists reusable media for CMS fields.

Authorization

PermissionCatalog exposes readable model view, add, change, and delete capabilities plus CMS capabilities. Use strict_permissions=True when exact action permissions are required. CasbinAuthorizationProvider is available as an optional adapter; PyCasbin is not a core dependency.

Microservice control plane

The control plane is enabled by default and is rooted at /admin/api/control-plane/. Use ServiceRegistry for service metadata, RemoteServiceClient for authenticated API calls, and RemoteModelAdapter for service-owned Admin models. Each service owns its database; Admin should not query another service's database directly.

from flaxon.admin import RemoteModelAdapter, RemoteServiceClient

catalog = RemoteServiceClient(
    "https://catalog.internal",
    token=service_token,
    timeout=3,
    retries=2,
)
admin.register(
    RemoteModelAdapter(catalog, "products"),
    name="product",
    fields=["id", "name", "price", "status"],
)

See the microservice control-plane guide for gateways, events, outbox delivery, Redis, object storage, and multi-worker deployment.
