WebSocketManager

WebSocket connection manager.

Methods

  • async join(room, socket) — Add connection to room
  • async leave(room, socket) — Remove connection from room
  • async leave_all(socket) — Remove from all rooms
  • async broadcast_text(room, message) — Broadcast text
  • async broadcast_json(room, data) — Broadcast JSON
  • async broadcast_bytes(room, data) — Broadcast bytes
  • get_room_size(room) — Get number of connections
  • get_rooms() — Get all room names
  • get_connection_rooms(socket) — Get rooms a connection is in
  • clear() — Clear all rooms and connections

WebSocketDisconnect

WebSocket disconnect exception.

WebSocketDisconnect(code: int = 1000, reason: str = "")

Attributes

  • code — Close code
  • reason — Close reason
Close Codes

1000 Normal, 1001 Going away, 1011 Internal error
