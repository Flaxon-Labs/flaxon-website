MemorySubscriptionBackend

MemorySubscriptionBackend(self)

In-process subscription backend, matching RedisSubscriptionBackend's interface.

Suitable for single-process deployments or local development. For multi-process or multi-server deployments, use RedisSubscriptionBackend instead so publishes from one process reach subscribers connected to another.
