Validators

  • required_validator(value, field) — Value must not be None
  • length_validator(min_length, max_length) — String/list length
  • min_validator(min_value) — Minimum value
  • max_validator(max_value) — Maximum value
  • range_validator(min_value, max_value) — Range
  • email_validator() — Email format
  • url_validator() — URL format
  • pattern_validator(pattern) — Regex pattern
  • and_validators(*validators) — Combine with AND
  • or_validators(*validators) — Combine with OR
  • custom_validator(func) — Custom validator function

Example 
class CreateUser(Schema):
    name = fields.String(required=True, min_length=2)
    email = fields.Email(required=True)

@app.post("/users")
async def create_user(data: CreateUser):
    return {"user": data.to_dict()}
