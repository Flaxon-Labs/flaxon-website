Routing API

Router

The main routing class used to register HTTP and WebSocket endpoints.

Constructor

Router(prefix: str = "")
````

### Parameters

| Parameter | Type | Description                               |
| --------- | ---- | ----------------------------------------- |
| prefix    | str  | Optional URL prefix applied to all routes |
